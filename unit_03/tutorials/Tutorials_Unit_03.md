## Tutorials Unit-03
## Arrays, Strings, Pointers, Structures, and Files in C

Each topic below includes at least two tutorial examples so the concept is practiced from both basic and applied viewpoints.

### 1. Arrays and array applications
| S. N. | Tutorial Problems |
| --- | --- |
| 1. | Read five daily rainfall readings into an array, print them, and calculate their sum and average. |
| 2. | Find the largest and smallest visitor counts among a few Indian heritage sites. |
| 3. | Read LED channel counts into an array and count how many are even and odd. |

### 2. Strings
| S. N. | Tutorial Problems |
| --- | --- |
| 4. | Read a line describing a local Indian tradition with `fgets()` and display its length using `strlen()`. Do not use `gets()`. |
| 5. | Copy an Indian city name into a sufficiently large character array with `strcpy()`, then compare the strings using `strcmp()`. |
| 6. | Input a heritage-site name and check whether it matches a stored reference string using `strcmp()`. |

### 3. Pointers
| S. N. | Tutorial Problems |
| --- | --- |
| 7. | Declare an integer for a phone battery percentage and an integer pointer. Display the value and address. |
| 8. | Use pointers to swap two sensor readings. |

### 4. Structures
| S. N. | Tutorial Problems |
| --- | --- |
| 9. | Define a `struct HeritageSite` with a name, state, and visitor count. Create one record and display each member. |
| 10. | Create an array of 3 `struct HeritageSite` records and print them in tabular form. |

### 5. File handling
| S. N. | Tutorial Problems |
| --- | --- |
| 11. | Write two lines about local heritage to a file, close it, reopen it, and display its contents. Check whether each `fopen()` succeeds. |
| 12. | Read a file of simple electronics readings, count how many readings are present, and print the result. |
