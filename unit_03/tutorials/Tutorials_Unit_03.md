## Tutorials Unit-03
## Arrays, Strings, Pointers, Structures, and Files in C

Each topic below includes at least two tutorial examples so the concept is practiced from both basic and applied viewpoints.

### 1. Arrays and array applications
| S. N. | Tutorial Problems |
| --- | --- |
| 1. | Read five integers into an array, print them, and calculate their sum and average. |
| 2. | Find and display the largest and smallest values in an integer array. |
| 3. | Read 10 numbers in an array and count how many are even and how many are odd. |

### 2. Strings
| S. N. | Tutorial Problems |
| --- | --- |
| 4. | Read a line of text with `fgets()` and display its length using `strlen()`. Do not use `gets()`. |
| 5. | Copy one string into a sufficiently large character array with `strcpy()`, then compare the strings using `strcmp()`. |
| 6. | Input a name and check whether it matches a stored reference string using `strcmp()`. |

### 3. Pointers
| S. N. | Tutorial Problems |
| --- | --- |
| 7. | Declare an integer and an integer pointer. Store the integer's address in the pointer, then display the value and address. |
| 8. | Use a pointer to swap the values of two variables without using a third variable. |

### 4. Structures
| S. N. | Tutorial Problems |
| --- | --- |
| 9. | Define a `struct Student` with a name, roll number, and marks. Create one student record and display each member. |
| 10. | Create an array of 3 `struct Student` records, input their details, and print them in tabular form. |

### 5. File handling
| S. N. | Tutorial Problems |
| --- | --- |
| 11. | Write two lines of text to a file, close it, reopen it, and display its contents. Check whether each `fopen()` succeeds. |
| 12. | Read a file, count how many words are present, and print the result on the screen. |
