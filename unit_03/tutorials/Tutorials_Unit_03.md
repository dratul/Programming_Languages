## Arrays, Strings, Pointers, Structures, and Files in C

Each topic below includes at least two tutorial examples so the concept is practiced from both basic and applied viewpoints.

The final column uses NBA Bloom's Taxonomy levels and action keywords to identify the thinking skill practiced.

### 1. Arrays and array applications
| S. N. | Tutorial Problems | Bloom's Level — Action Keyword |
| --- | --- | --- |
| 1. | Read five daily rainfall readings into an array, print them, and calculate their sum and average. | Apply — Calculate |
| 2. | Find the largest and smallest visitor counts among a few Indian heritage sites. | Analyze — Compare |
| 3. | Read LED channel counts into an array and count how many are even and odd. | Analyze — Classify |
