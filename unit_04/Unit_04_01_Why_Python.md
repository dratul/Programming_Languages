# 4.1 Introduction to Python

## What Is Python?

Python is a high-level, general-purpose programming language. Its syntax is designed to be readable, so beginners can focus on solving problems instead of writing a lot of setup code.

Python is an interpreted language: a Python interpreter reads and runs a program. Python programs are commonly saved in files ending in `.py`.

## Why Learn Python?

Python is useful for learning programming because:

* Its readable syntax makes programs easier to understand.
* It supports common programming ideas such as variables, decisions, loops, and functions.
* It can be used in many different fields.
* A large community creates learning resources and libraries for Python.

## Where Is Python Used?

| Area | Example uses |
| --- | --- |
| **Artificial intelligence (AI)** | Building and experimenting with intelligent applications |
| **Data science** | Organizing, analyzing, and visualizing data |
| **Web development** | Creating the server-side parts of websites |
| **Automation** | Automating repetitive computer tasks |

These are examples of areas where Python is used. This unit focuses on the language basics needed before studying larger applications.

## A First Python Program

```python
print("Hello, Python!")
```

`print()` displays text on the screen. Python does not require a semicolon at the end of this statement.

**Output:**

```text
Hello, Python!
```

## Python and C

Both C and Python let us store data, make decisions, repeat instructions, and organize code into functions. Python generally needs less syntax for a small program. For example:

```python
print("Welcome")
```

The equivalent C program needs a `main()` function and the `stdio.h` header. The languages have different strengths, but the problem-solving concepts are shared.

## Key Points

* Python is a readable, high-level, general-purpose language.
* Python is used in AI, data science, web development, and automation.
* A Python program can be saved in a `.py` file and run with a Python interpreter.
* This unit introduces Python syntax and programming fundamentals.
