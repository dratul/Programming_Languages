## Tutorials Unit-04
## Python Introduction

Each topic below includes at least two tutorial examples so students can practice both the syntax and the logic behind Python programs.

### 1. Why Python and Python basics
| S. N. | Tutorial Problems |
| --- | --- |
| 1. | Print your name, branch, and college using `print()`. |
| 2. | Read two numbers and display their sum, difference, product, and quotient. Convert the input to numbers before calculating. |
| 3. | Read the length and breadth of a rectangle and display its area. |

### 2. Python control flow
| S. N. | Tutorial Problems |
| --- | --- |
| 4. | Read an integer and use `if`/`else` to report whether it is even or odd. |
| 5. | Read marks and use `if`/`elif`/`else` to print a grade. |
| 6. | Use a `for` loop and `range()` to print the multiplication table for a number. |
| 7. | Use a `while` loop to add numbers from 1 through 10 and print the total. |

### 3. Python functions
| S. N. | Tutorial Problems |
| --- | --- |
| 8. | Define a function that takes two numbers and returns their sum. Call it and print the result. |
| 9. | Define a function with a default argument, such as a greeting message, and call it with and without the optional argument. |
| 10. | Write a function that takes a number and returns `True` if it is prime, otherwise `False`; test it on a few values. |
