## Tutorials Unit-04
## Python Introduction

Each topic below includes at least two tutorial examples so students can practice both the syntax and the logic behind Python programs.

### 1. Why Python and Python basics
| S. N. | Tutorial Problems |
| --- | --- |
| 1. | Print your name, branch, college, and an Indian city or tradition you value using `print()`. |
| 2. | Read two rupee amounts for a local community event and display their sum, difference, product, and quotient. Convert the input to numbers before calculating. |
| 3. | Read the length and breadth of a small solar panel and display its area. |

### 2. Python control flow
| S. N. | Tutorial Problems |
| --- | --- |
| 4. | Read a phone's number of LED channels and use `if`/`else` to report whether the count is even or odd. |
| 5. | Read a phone battery percentage and use `if`/`elif`/`else` to print a charging status. |
| 6. | Use a `for` loop and `range()` to print the multiplication table for the number of panels in a local solar installation. |
| 7. | Use a `while` loop to total visitor counts from a local heritage event. |

### 3. Python functions
| S. N. | Tutorial Problems |
| --- | --- |
| 8. | Define a function that takes two community event volunteer counts and returns their total. Call it and print the result. |
| 9. | Define a function with a default greeting such as `"Namaste"` and call it with and without the optional argument. |
| 10. | Write a function that takes a number and returns `True` if it is prime, otherwise `False`; test it on a few values. |
