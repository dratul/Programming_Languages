## Tutorials Unit-04
## Python Introduction

Each topic below includes at least two tutorial examples so students can practice both the syntax and the logic behind Python programs.

The final column uses NBA Bloom's Taxonomy levels and action keywords to identify the thinking skill practiced.

### 1. Why Python and Python basics
| S. N. | Tutorial Problems | Bloom's Level — Action Keyword |
| --- | --- | --- |
| 1. | Print your name, branch, college, and an Indian city or tradition you value using `print()`. | Apply — Format |
| 2. | Read two rupee amounts for a local community event and display their sum, difference, product, and quotient. Convert the input to numbers before calculating. | Apply — Calculate |
| 3. | Read the length and breadth of a small solar panel and display its area. | Apply — Calculate |

### 2. Python control flow
| S. N. | Tutorial Problems | Bloom's Level — Action Keyword |
| --- | --- | --- |
| 4. | Read a phone's number of LED channels and use `if`/`else` to report whether the count is even or odd. | Apply — Classify |
| 5. | Read a phone battery percentage and use `if`/`elif`/`else` to print a charging status. | Apply — Classify |
| 6. | Use a `for` loop and `range()` to print the multiplication table for the number of panels in a local solar installation. | Apply — Generate |
| 7. | Use a `while` loop to total visitor counts from a local heritage event. | Apply — Calculate |

### 3. Python functions
| S. N. | Tutorial Problems | Bloom's Level — Action Keyword |
| --- | --- | --- |
| 8. | Define a function that takes two community event volunteer counts and returns their total. Call it and print the result. | Apply — Implement |
