# Programming_Languages

**Instructor:** Dr Atul Kumar Dwivedi  
**Institution:** BIET Jhansi

For first-year students of institutes affiliated with AKTU Lucknow.

Examples across the course use inclusive Indian civic, cultural, and everyday
contexts, alongside familiar electronics such as phones, LEDs, and sensors.
Students are welcome to adapt names, places, and data to their own communities.

## Course at a glance

| Item | Details |
| --- | --- |
| University / programme | Dr. A.P.J. Abdul Kalam Technical University, Lucknow — B.Tech. First Year, ECE Stream |
| Course code and title | ACS101 — Programming Languages |
| Credits / NCrF hours | 3 credits / 45 hours |
| Languages | C and Python |
| Suggested tools | GCC, Code::Blocks, or VS Code for C; Google Colab or Jupyter for Python |
| Unit weightage | 20% per unit |

The syllabus evaluation pattern is **Class Tests: 15 marks (15%)**, **Teacher's
Assessment: 15 marks (15%)**, and **End-Semester Examination: 70 marks (70%)**.
Teaching uses short concept-focused lectures, live coding, debugging, and a
compulsory hands-on tutorial hour each week. Google Colab can be used for
Python without a local installation.

### Course objectives

Students will learn to write, compile, and run C and Python programs; solve
simple problems with variables, operators, and control flow; use functions,
arrays, and basic string operations; use Python's built-in data types; and
apply Python to a small data, automation, or IoT task.

### Course outcomes

| Outcome | By the end of the course, students can |
| --- | --- |
| CO1 | Write, compile, and run C programs using variables, operators, and input/output. |
| CO2 | Use C control flow and functions to solve simple computational problems. |
| CO3 | Work with C arrays and strings and explain the basic pointer concept. |
| CO4 | Perform basic operations using Python built-in data structures. |
| CO5 | Use Python to read files, plot data, and complete a small emerging-domain task. |

## Maintainer Check

Run the repository checks from the root folder with Python 3:

```powershell
python scripts\validate_examples.py
```

The script checks local Markdown links and code fences, validates Python examples, and syntax-checks standalone C files when GCC is available.
