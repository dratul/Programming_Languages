## Tutorials Unit-02
## Decision Making, Loops, and Functions in C

| S. N. | Tutorial Problems |
| --- | --- |
| 1. | Read an integer and report whether it is positive, negative, or zero. |
| 2. | Read marks from 0 to 100 and display a grade using an `if`/`else if` ladder. Reject values outside the range. |
| 3. | Build a calculator for two numbers using `switch`; handle division by zero. |
| 4. | Use a `for` loop to print the multiplication table for a number entered by the user. |
| 5. | Use a `while` loop to add positive integers until the user enters zero. |
| 6. | Use a `do-while` loop to display a menu at least once, then repeat it until the user chooses to exit. |
| 7. | Print the numbers from 1 to 20, skipping multiples of 3 with `continue` and stopping at 17 with `break`. |
| 8. | Write a function that accepts two integers and returns their greatest common divisor. |
| 9. | Write a function to find the largest of three integers; explain why changing a parameter does not change the caller's variable. |
| 10. | Write a recursive function to calculate the factorial of a non-negative integer. |
| 11. | Write a recursive function to print the first 10 Fibonacci numbers. |
