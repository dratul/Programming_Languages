## Tutorials Unit-03
## Arrays, Strings, Pointers, Structures, and Files in C

| S. N. | Tutorial Problems |
| --- | --- |
| 1. | Read five integers into an array, print them, and calculate their sum and average. |
| 2. | Find and display the largest and smallest values in an integer array. |
| 3. | Read a line of text with `fgets()` and display its length using `strlen()`. Do not use `gets()`. |
| 4. | Copy one string into a sufficiently large character array with `strcpy()`, then compare the strings using `strcmp()`. |
| 5. | Declare an integer and an integer pointer. Store the integer's address in the pointer, then display the value and address. |
| 6. | Define a `struct Student` with a name, roll number, and marks. Create one student record and display each member. |
| 7. | Write two lines of text to a file, close it, reopen it, and display its contents. Check whether each `fopen()` succeeds. |
