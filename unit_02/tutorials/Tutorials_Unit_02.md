## Tutorials Unit-02
## Decision Making, Loops, and Functions in C

Each topic below includes at least two tutorial examples to build confidence in selection, repetition, and modular logic.

### 1. Decision making and control statements
| S. N. | Tutorial Problems |
| --- | --- |
| 1. | Read a phone battery percentage and report whether it is low, moderate, or high; reject values outside 0–100. |
| 2. | Read the number of volunteers at an event and classify the group size using an `if`/`else if` ladder. |
| 3. | Use `switch` to display information about one of three Indian heritage sites. |

### 2. Loops
| S. N. | Tutorial Problems |
| --- | --- |
| 4. | Use a `for` loop to print the multiplication table for the number of LED channels in a device. |
| 5. | Use a `while` loop to total visitor counts until the user enters zero. |
| 6. | Use a `do-while` loop to display a community event information menu at least once, then repeat it until the user exits. |
| 7. | Print checkpoint numbers from 1 to 20, skipping reserved checkpoints with `continue` and stopping at 17 with `break`. |

### 3. Functions and recursion
| S. N. | Tutorial Problems |
| --- | --- |
| 8. | Write a function that accepts two counts of event supplies and returns their greatest common divisor. |
| 9. | Write a function to find the largest of three heritage-site visitor counts; explain why changing a parameter does not change the caller's variable. |
| 10. | Write a recursive function to calculate the factorial of a non-negative integer. |
| 11. | Write a recursive function to print the first 10 Fibonacci numbers. |
