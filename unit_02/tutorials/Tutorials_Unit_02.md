## Decision Making, Loops, and Functions in C

Each topic below includes at least two tutorial examples to build confidence in selection, repetition, and modular logic.

The final column uses NBA Bloom's Taxonomy levels and action keywords to identify the thinking skill practiced.

### 1. Decision making and control statements
| S. N. | Tutorial Problems | Bloom's Level — Action Keyword |
| --- | --- | --- |
| 1. | Read a phone battery percentage and report whether it is low, moderate, or high; reject values outside 0–100. | Apply — Classify |
| 2. | Read the number of volunteers at an event and classify the group size using an `if`/`else if` ladder. | Apply — Classify |
| 3. | Use `switch` to display information about one of three Indian heritage sites. | Apply — Select |
