## Python Data Structures and Emerging Applications

Each topic below includes at least two tutorial examples so the theory is reinforced with practical exercises.

### 1. Python data structures
| S. N. | Tutorial Problems |
| --- | --- |

| 3. | Create a dictionary for a student with a name, roll number, and branch. Print each value using its key. |
