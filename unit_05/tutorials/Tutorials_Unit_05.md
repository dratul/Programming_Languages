## Tutorials Unit-05
## Python Data Structures and Emerging Applications

These beginner exercises follow the Unit 5 syllabus. Install NumPy and Matplotlib before attempting the exercises that use them.

| S. N. | Tutorial Problems |
| --- | --- |
| 1. | Create a list of five marks. Print the list, its first mark, its length, and the average of the marks. |
| 2. | Create a tuple containing an `(x, y)` point and print each coordinate. Try to explain why tuple items cannot be reassigned. |
| 3. | Create a dictionary for a student with a name, roll number, and branch. Print each value using its key. |
| 4. | Create a set from a list containing repeated numbers and print the distinct values. |
| 5. | Write three lines to a text file using `with open(...)`, then open the file again and print its contents. |
| 6. | Create a small CSV file with two columns, such as `Name` and `Marks`, and read its rows using Python's built-in `csv` module. |
| 7. | Create a NumPy array of five readings. Print the array, its mean using `np.mean()`, and the result of adding a number to each element. |
| 8. | Use Matplotlib to plot a line graph of four sample readings against their measurement numbers. Add a title and axis labels. |
| 9. | Simulate five temperature readings, store them in a list, and display the readings and their average. |
