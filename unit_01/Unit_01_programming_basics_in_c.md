# Unit 1: Programming Basics (C)

**Instructor:** Dr Atul Kumar Dwivedi  
**Institution:** BIET Jhansi

This unit introduces the C language and the programming fundamentals used throughout the course. The original Unit 1 lesson has been organized into the following topic files; its lesson content and examples are preserved in those files.

## Lessons

1. [Introduction to C](Unit_01_01_Introduction_to_C.md) — syllabus, history, why C is taught, language overview, practice platforms, and quick quiz.
2. [Program structure, input/output, and compilation](Unit_01_02_Program_Structure_and_Compilation.md) — basic C program structure, `printf`/`scanf`, and the compile/run process.
3. [Data types and variables](Unit_01_03_Data_Types_and_Variables.md) — data types, ranges, variables, and constants.
4. [Operators and expressions](Unit_01_04_Operators.md) — arithmetic, relational, logical, bitwise operators, and precedence.
5. [Type conversion](Unit_01_05_Type_Conversions.md) — implicit conversion, casts, integer division, and examples.
