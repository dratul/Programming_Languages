## Tutorials Unit-01
## Basics of C

Each topic below includes at least two tutorial examples so students can practice the concept from different angles.

### 1. Program structure and input/output
| S. N. | Tutorial Problems |
| --- | --- |
| 1. | Write a program using C to print your name, branch, and an Indian city or community tradition you value. |
| 2. | Write a program using C to add two counts from a local community event. |

### 2. Data types and variables
| S. N. | Tutorial Problems |
| --- | --- |
| 3. | Write a program using C to find the area of a small solar panel from its length and breadth. |
| 4. | Write a program using C to calculate the area of a circular community garden bed. |

### 3. Operators and expressions
| S. N. | Tutorial Problems |
| --- | --- |
| 5. | Write a program using C to swap two sensor readings using a temporary variable. |
| 6. | Write a program using C to input visitor counts for three local heritage sites and display their total and average. |

### 4. Type conversion and expressions
| S. N. | Tutorial Problems |
| --- | --- |
| 7. | Use visitor counts to demonstrate integer division and explain how explicit casting changes the average. |
| 8. | Write a program using C to convert a weather-station temperature from Celsius to Fahrenheit and print two decimal places. |
