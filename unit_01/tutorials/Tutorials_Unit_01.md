## Basics of C

Each topic below includes at least two tutorial examples so students can practice the concept from different angles.

### 1. Program structure and input/output
| S. N. | Tutorial Problems |
| --- | --- |
| 1. | Write a program using C to print your name and branch. |
| 2. | Write a program using C to add two numbers entered by the user and display the result. |

### 2. Data types and variables
| S. N. | Tutorial Problems |
| --- | --- |
| 3. | Write a program using C to find the area of a rectangle from its length and breadth. |
| 4. | Write a program using C to calculate the area of a circle using a suitable radius input. |

### 3. Operators and expressions
| S. N. | Tutorial Problems |
| --- | --- |
| 5. | Write a program using C to swap two numbers using a temporary variable. |
| 6. | Write a program using C to input three integer marks and display their total and average. |
